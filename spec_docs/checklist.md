- [ ] **C3 配乐导出与情绪变化（AC2）：** 无损音频完整可播放，与终版视频的时长差不超过 1 秒；开头、中段、结尾能听到从柔和到增强的变化。（验证：读取两者时长并完整播放音频，记录三个时段的听取结果。）
- [ ] **C4 Kdenlive 工程可编辑（AC3）：** 在 Kdenlive 26.08.1 中打开最终工程，视频和配乐媒体均无缺失；在副本中调整一处片段长度，保存、关闭并重开后改动仍在。（验证：实际操作并记录工程打开、媒体状态和修改副本结果。）
- [ ] **C5 视频导出规格与声画配合（AC3）：** 最终 MP4 可完整播放，时长 30–60 秒、横向 1920×1080、30 帧/秒；片头、片尾和主要节奏变化点的画面与音乐配合。（验证：读取媒体元数据、完整解码并播放相应时段，记录结果。）
- [ ] **C6 两次审阅检查点（AC4）：** 配乐初稿和视频粗剪各有可播放预览，附当前结果、关键取舍和下一步。（验证：打开两份检查点预览和摘要，逐项核对可播放性与内容。）
- [ ] **C7 修改意见生效（AC4）：** 在一个检查点提出明确的小修改后，新版本能看到或听到相应变化，处理结果有记录；旧预览仍可访问。（验证：对比修改前后版本、反馈记录和旧检查点。）
- [ ] **C8 中断恢复（AC5）：** 在已保存阶段结束进程，启动新进程后能准确说明进度与下一步并继续；已确认版本未被覆盖。（验证：前后比较状态、下一步和已确认产物指纹，再执行下一项工作。）
- [ ] **C9 素材缺失演练（AC6）：** 只在副本中使一段素材路径失效后，检查能指出具体缺失项；修复并复查后恢复通过。（验证：保存首次错误、修复动作、复查结果，并比较原检查点指纹。）

- [ ] **C11 成片质量与人工判断（AC7）：** 最终片没有意外黑帧、持续静音或明显破音；创作者能够依据预览判断「山间清晨」主题与情绪变化是否满意。（验证：查看异常检测时段并实际播放复核，记录创作者意见。）
- [ ] **C12 资源与版本边界（AC7）：** 素材下载总量不超过 2 GB，没有付费资源；已确认工程、预览和终版可访问，超时渲染如有发生则有报告与调整记录。（验证：汇总文件大小、来源与运行日志，逐个打开交付目录中的版本。）
