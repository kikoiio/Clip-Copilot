# 山间清晨短片 Spec

> 状态：已于 2026-10-01 获用户批准。

## 背景

项目愿景是让助手在 Kdenlive 与 LMMS 中持续协作，交付可编辑作品，并依据实际产物验证结果。当前工作区只有愿景文档，还没有创作素材、实现代码或可复用的工作流程。第一轮选择一支 30–60 秒的跨软件短片，作为可检查的完整样板。

短片主题定为「山间清晨」：画面从安静的溪流、晨雾或日出，逐步转向明亮、流动感更强的森林与山景；原创电子配乐从稀疏、柔和逐渐增强。视频使用允许免费改编且无需署名的公开素材。素材的来源和使用条件需记录，具体片段在制作前核验。

首批素材候选为 [山谷日出与河流](https://www.pexels.com/video/scenic-mountain-valley-at-sunrise-with-river-flow-31491768/)、[森林溪流特写](https://www.pexels.com/video/close-up-of-a-forest-river-flowing-12356024/) 和 [阳光下的森林航拍](https://www.pexels.com/video/aerial-view-of-lush-forest-in-sunlight-29311838/)。这些页面标注可免费下载；[Pexels 许可说明](https://www.pexels.com/license/)允许免费使用、改编且不要求署名。实际采用前还需核验文件可获取、画质、时长及适用条件。

## 目标

- 交付一支主题和情绪变化清晰的 30–60 秒短片，同时保留可打开、可继续编辑的 LMMS 配乐工程和 Kdenlive 剪辑工程。
- 在约定的检查点提供可预览版本，让创作者能够提出修改，再继续下一阶段。
- 以实际打开工程、检查媒体引用和播放导出文件的结果判断交付是否成功。
- 演练一次任务中断后的继续工作，并保留足以说明当前进度、重要决定和下一步的记录。

## 功能需求

- **F1 素材准备：** 选择足以完成短片的公开视频片段；逐项记录来源、使用条件和本地素材状态。采用前确认素材可获取、可播放，并符合免费改编且无需署名的条件。若候选片段不可用，换用符合相同条件的素材并记录替换原因。
- **F2 配乐制作：** 在 LMMS 中制作与短片时长相配的原创配乐，导出音频与最终视频的时长差不超过 1 秒，情绪从稀疏、柔和逐渐增强；交付可继续编辑的配乐工程和可供视频使用的音频导出文件。
- **F3 视频制作：** 在 Kdenlive 中使用所选素材完成 30–60 秒的「山间清晨」短片；镜头与配乐的起止、主要节奏变化相协调；交付可继续编辑的剪辑工程、可预览版本和最终视频。
- **F4 阶段协作：** 配乐初稿完成后提供一次检查点，视频粗剪完成后提供一次检查点。每次说明当前结果、关键取舍和下一步，并提供可播放的预览；收到创作者的修改意见后，将其纳入后续工作。
- **F5 中断恢复：** 保存目标、素材清单、阶段状态、重要决定和下一步。在一次有意中断并重新开始工作后，依据这些记录和现有工程继续，避免覆盖已确认的成果。
- **F6 实际验证与问题处理：** 检查两个工程能否打开、所需媒体是否可用，以及音频和视频导出能否播放。发现缺失素材或导出失败时，在已授权范围内尝试修复并重新验证；仍未解决的问题要明确报告。

## 非功能需求

- **N1 兼容性：** 可编辑工程须能在当前安装的 Kdenlive 26.08.1 和 LMMS 1.2.2 中打开；交付文件应集中保存，并避免依赖临时下载路径。
- **N2 输出质量：** 视频默认采用横向 16:9、1920×1080、30 帧/秒，提供常见播放器可播放的 MP4；配乐另提供可供剪辑使用的无损音频文件。这些规格为第一轮默认值，若素材能力不足，须先说明并调整。
- **N3 内容质量：** 最终片应没有缺失媒体、意外黑帧或明显音频失真；情绪与节奏变化须能从画面和声音中观察到。审美是否满意由创作者在检查点判断，不能仅凭导出成功判定。
- **N4 安全与可追溯：** 保留已确认的工程与预览版本；修改、素材替换和失败修复须留下原因及结果，继续工作时不得静默覆盖这些版本。
- **N5 资源边界：** 第一轮默认只使用免费公开素材和本机工具，不启用付费服务；素材下载总量以 2 GB 为默认上限。若达到上限或单次渲染超过 30 分钟，应报告现状并调整方案。
- **N6 可恢复性：** 进度与下一步应保存在工作区中，以便脱离当前对话仍能理解和继续；恢复不依赖一个持续运行的模型会话或桌面进程。

## 不做的事

- 不开发可处理任意题材、任意时长作品的通用创作助手；第一轮只验证这支 30–60 秒样板。
- 不读取或推断 Kdenlive、LMMS 中尚未保存的实时编辑状态；以已保存工程和实际导出文件为依据。
- 不在创作者同时编辑同一工程时自动改写该工程；检查点之后再继续助手负责的修改。
- 不持续监测工作区，也不在无人值守状态下跨多天主动推进。中断恢复仅演练一次明确的停止与继续。
- 不自动判断作品的全部审美质量；创作者在检查点决定主观取舍。
- 不负责将成片发布到网站或社交平台，也不采购素材、插件或云服务。

## 验收标准

- **AC1（F1）：** 查看最终使用的每段素材，都能找到来源页面、当时核验的使用条件和本地文件记录；逐一打开本地文件均可播放。若首批候选被替换，记录中能看到原因和替代素材。
- **AC2（F2）：** 在当前 LMMS 版本中打开配乐工程，能看到可修改的音轨和编排；在副本中修改并保存一处内容后仍能重新打开。导出的无损音频可完整播放，与最终视频的时长差不超过 1 秒，能听到从柔和到增强的变化。
- **AC3（F3）：** 在当前 Kdenlive 版本中打开剪辑工程，媒体无缺失，画面与配乐均可继续编辑。最终 MP4 可完整播放，时长为 30–60 秒，画面为横向 1920×1080、30 帧/秒；起止与主要节奏变化处的声画配合经播放检查。
- **AC4（F4）：** 配乐初稿和视频粗剪各有一次可播放的检查点，并附当前结果、关键取舍和下一步；若创作者提出明确修改，下一版可观察到相应变化，并记录处理结果。
- **AC5（F5）：** 在一个已保存的阶段有意停止工作，重新开始时只依据工作区记录和工程便能说明进度、找到下一步并继续；已确认的工程和预览版本仍可访问，且未被静默覆盖。
- **AC6（F6）：** 在交付副本中分别模拟一次素材路径失效和一次导出失败，助手能识别原因、记录处理过程，并在修复后重新验证；若无法修复，交付报告准确标明未解决项。
- **AC7（N3–N5）：** 播放最终成片，检查无意外黑帧、持续静音或明显破音；创作者能够依据预览判断主题与情绪变化是否满意。交付记录说明已保留的版本、素材下载量和是否使用付费资源。
